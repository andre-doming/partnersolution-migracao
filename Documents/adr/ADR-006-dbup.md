# ADR 006 — DbUp para migrations (placeholder)

## Status
Registrada (placeholder)

## Contexto
DbUp pode ser utilizado futuramente para versionamento de schema em ambientes controlados.

## Decisão
**Não adotado nesta fase**. Registrado como opção para evolução.

## Consequências
- Sem migrations automatizadas nesta etapa.
- Evolução futura deve definir estratégia (DbUp/Flyway/etc.).
